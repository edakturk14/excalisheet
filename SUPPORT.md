# Excalisheet Support

Need help with Excalisheet?

Open a GitHub issue:

https://github.com/edakturk14/excalisheet/issues

Please include:

- what you asked Excalisheet to do
- whether you used Diagram or Cheat sheet mode
- the source type, such as pasted text or a public docs URL
- what you expected
- what happened instead

Do not post private documents, API keys, passwords, or other sensitive information in a public issue.
