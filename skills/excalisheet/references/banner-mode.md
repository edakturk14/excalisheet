# Banner mode

Banner mode turns technical content into a clean landscape social visual.

## Default format

- X/social banner
- 3:1 landscape
- PNG
- one main idea
- one focal point
- minimal copy

## Content hierarchy

Prefer:
1. one short title
2. optional short subtitle
3. optional 2-5 terms

Do not turn the banner into a cheat sheet.

## Inputs

The user may provide:
- a post
- notes
- a docs URL
- terms
- 1-3 images
- a style direction

If the source is long, extract the single strongest idea.
If the user supplies terms, keep only the ones that improve the composition.
If the user supplies images, use them intentionally and preserve important details.

## Visual direction

Default to a clean developer-tool/editorial feel.

Use:
- clear hierarchy
- strong whitespace
- restrained palette
- simple shapes
- one dominant visual motif

Avoid:
- crowded collages
- generic futuristic AI imagery
- gradients, blobs, sparkles, or random decoration
- long text
- tiny text
- over-designed infographic layouts

## Quality test

A good banner should still make sense when seen quickly in an X feed or profile header.

If an element does not improve recognition or meaning, remove it.
