# Cheat sheet mode

Cheat sheet mode turns longer technical content into one story.

## Target

A reader should understand the main narrative in under 30 seconds.

Use 4-6 sections maximum.

Each section contains:
- a number
- a short question/title
- one short "why" sentence
- one simple diagram

## Narrative test

The sections should behave like questions.

For example:

1. What is the thing?
2. Where does it run?
3. What does it receive?
4. What happens to the request?
5. How does this work at scale?

These are examples, not a required template.

The next question should feel natural after reading the previous answer.

## In short

End with 4-6 steps.

Example:

`app prepares request → routing picks server → input becomes tokens → GPU processes → answer returns`

The summary must not introduce a concept that did not appear above.

## Compression

Do not preserve every section from the source.

The source may contain ten interesting concepts. The visual may need five.

This is expected.

The goal is understanding, not completeness.
