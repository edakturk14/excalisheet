# Style guide

## Goal

A restrained developer-tool editorial visual that feels designed, not decorated.

The graphic should be easy to scan in seconds.

## Canvas

- White background.
- Generous margins.
- Thin light-gray panel outlines.
- Large whitespace between ideas.
- Avoid filling empty space just because it exists.

## Typography

Use Excalidraw / Virgil.

Hierarchy:
- title: 36-42
- subtitle: 20-23
- section title: 24-28
- box title: 20-23
- body: 15-18
- annotations: 13-15

Do not bold everything.

## Color

Default:
- text: `#1E1E1E`
- secondary: `#555555`
- border: `#C9C9C9`
- soft border: `#D8D8D8`
- accent: `#7C5CFC`
- accent tint: `#F4F0FF`

Use the accent sparingly.

One accent is enough.

## Diagrams

Prefer:
- boxes
- arrows
- small labels
- simple branching
- simple stacks

Avoid:
- 3D
- decorative backgrounds
- illustrations that do not explain something
- duplicate labels
- icons where words are clearer

## The deletion test

For every visual element ask:

> If I remove this, does the reader understand the same thing?

If yes, remove it.
