# Diagram mode

Diagram mode explains one concept.

## Target

A reader should understand the core idea in 5-10 seconds.

Use:
- one title
- one visual relationship
- 2-5 concepts
- minimal labels

Do not turn a diagram into a mini cheat sheet.

## Process

1. Write the question.
2. Write the answer in one sentence.
3. Identify the 2-5 things needed to show that answer.
4. Pick the simplest layout.
5. Remove explanatory prose that the geometry already communicates.

## Examples

"ChatGPT is not the model"

`ChatGPT (app) → GPT (model)`

"Where does the model run?"

`server → CPU/RAM + GPU/VRAM`

"Which server gets the request?"

`request → router → server A/B/C`
